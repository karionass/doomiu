# Контракт API (фронтенд ⇄ бэкенд)

Для Карины. Фронтенд уже написан под этот контракт — если что-то хочется поменять, пишите друг другу **до** изменений.

## Общее

- Базовый адрес: `http://localhost:8000`, все пути начинаются с `/api/`.
- Формат: JSON. Авторизация: заголовок `Authorization: Bearer <access>` (JWT, `djangorestframework-simplejwt`).
- Даты `"2026-10-15"`, время `"09:00"` (формат `HH:MM:SS` тоже ок, фронт обрежет).
- CORS: разрешить `http://localhost:5173` (`django-cors-headers`).
- Списки отдаём **без пагинации** (или с DRF-пагинацией `{"results": [...]}` — фронт понимает оба варианта).
- Пользователь видит и меняет только **свои** данные.
- Запись должна быть **идемпотентной**: при плохой связи фронт ставит запросы в очередь и может отправить их повторно.

## Авторизация

| Метод и адрес | Тело запроса | Ответ |
|---|---|---|
| `POST /api/auth/register/` | `{"name","email","password"}` | `201`. Если email занят — `400 {"email":["..."]}` |
| `POST /api/auth/login/` | `{"email","password"}` | `200 {"access","refresh"}`; неверные данные — `401` |
| `POST /api/auth/refresh/` | `{"refresh"}` | `200 {"access"}` (можно и новый `refresh`) |
| `GET /api/auth/me/` | — | `{"email","name","timezone","language","theme"}` |
| `PATCH /api/auth/me/` | любые из полей выше (кроме email) | обновлённый профиль |

- Вход по **email** (в simplejwt поле `email` вместо `username`).
- `timezone` — например `"Asia/Almaty"`; `language` — `"ru" | "en" | "kk"`; `theme` — `"light" | "dark"`.
- Вход через Google (OAuth) — позже, на фронте кнопки пока нет.

## Привычки

Объект привычки:

```json
{
  "id": 1,
  "name": "Пить 2 л воды",
  "icon": "💧",
  "category": "health",
  "freq": "daily",
  "days": [],
  "times_per_week": 3,
  "reminder_time": "09:00",
  "archived": false,
  "created_at": "2026-10-01T10:00:00Z",
  "completions": ["2026-10-13", "2026-10-14"]
}
```

- `category`: `health | study | work | rest | home | other` (хранится ключом, перевод на фронте).
- `freq`: `daily` (каждый день) | `days` (по дням недели, список в `days`) | `times` (N раз в неделю, число в `times_per_week`).
- `days`: числа 0–6, **0 = воскресенье, 1 = понедельник … 6 = суббота**.
- `reminder_time`: `null` или время напоминания (по часовому поясу пользователя).
- `completions`: даты, когда привычка выполнена (из этого фронт считает streak и статистику).

| Метод и адрес | Тело | Ответ |
|---|---|---|
| `GET /api/habits/` | — | список привычек, **включая архивные** |
| `POST /api/habits/` | `name, icon, category, freq, days, times_per_week, reminder_time` | `201` + объект привычки |
| `PATCH /api/habits/{id}/` | любые поля (фронт шлёт `{"archived": true}`) | объект |
| `DELETE /api/habits/{id}/` | — | `204` |
| `POST /api/habits/{id}/check/` | `{"date": "2026-10-15", "done": true}` | `200` или `204` |

`check`: `done: true` — создать отметку за дату (если уже есть — ничего не делать), `done: false` — удалить.

## Настроение

Запись: `{"date": "2026-10-15", "level": 4, "tags": ["work", "sleep"], "note": "текст"}`

- `level` 1–5. `tags` — список ключей: `work, study, sleep, relations, family, friends, health, sport`.
- Одна запись на пользователя и день.

| Метод и адрес | Тело | Ответ |
|---|---|---|
| `GET /api/mood/` | — | список записей |
| `PUT /api/mood/{date}/` | `{"level","tags","note"}` | создать **или** заменить запись за дату (`200`/`201`) |
| `DELETE /api/mood/{date}/` | — | `204` (если записи нет — `204` или `404`, не важно) |

## Дневник благодарности

Запись: `{"date": "2026-10-15", "items": ["чай", "солнце", "звонок маме"]}` (до 3 строк, могут быть пустыми).

| Метод и адрес | Тело | Ответ |
|---|---|---|
| `GET /api/gratitude/` | — | список записей |
| `PUT /api/gratitude/{date}/` | `{"items": [...]}` | создать или заменить запись за дату |

## Что на чьей стороне

- **Фронт** считает streak, графики и тепловую карту из `completions` и записей настроения; экспорт CSV и PDF тоже на фронте. Бэкенду это делать не нужно.
- **Бэкенд**: хранение, email-напоминания по `reminder_time` + `timezone` (cron/Celery, Redis нужен только для Celery), админка, тесты.
- Создание привычки (`POST /api/habits/`) требует связи — остальные действия работают офлайн и досылаются позже.

## Проверка вместе перед защитой

1. В `mindful/.env`: `VITE_API_URL=http://localhost:8000`, `npm run dev`.
2. Регистрация → вход → создать привычку → отметить → обновить страницу (данные на месте).
3. Настроение и благодарность сохраняются и видны после перезагрузки.
4. Выключить сеть в DevTools → отметить привычку → включить сеть: отметка должна появиться на сервере.
