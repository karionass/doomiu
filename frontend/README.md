# Mindful — фронтенд трекера привычек и ментального здоровья

React + Vite. Пастельный дизайн, котики для настроения, светлая и тёмная тема, адаптивность, языки RU / EN / KZ, PWA.

## Запуск

Нужен [Node.js LTS](https://nodejs.org).

```bash
npm install
npm run dev        # http://localhost:5173
```

Сборка: `npm run build`, проверка сборки (с PWA и офлайном): `npm run preview`.

Если PowerShell пишет «выполнение сценариев отключено»:
`Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned`

## Два режима работы

| Режим | Когда | Что происходит |
|---|---|---|
| **Демо** | файла `.env` нет | сервер не нужен, вход ничего не проверяет, всё хранится в браузере. Демо-данные: Настройки → «Загрузить демо-данные» |
| **С бэкендом** | в `.env` задан `VITE_API_URL` | настоящие регистрация и вход, данные на сервере |

Подключить бэкенд Карины: скопируй `.env.example` в `.env`, раскомментируй строку `VITE_API_URL=http://localhost:8000` и перезапусти `npm run dev`. Адреса и форматы данных — в **[API.md](API.md)**.

## Что есть

- Привычки: иконка, категория, периодичность (каждый день / дни недели / N раз в неделю), напоминание, streak, архив.
- Настроение: котики 1–5, теги, заметка, календарь.
- Статистика: графики, тепловая карта, экспорт CSV и PDF.
- Упражнения: дыхание 4-7-8 и квадратное, медитация, Pomodoro, дневник благодарности.
- Вход и регистрация, язык, часовой пояс, тема.
- Офлайн: приложение открывается без сети; отметки, настроение и благодарность досылаются на сервер, когда сеть вернётся.

## Структура

```
src/
  api.js          запросы к бэкенду, токены, офлайн-очередь
  AppContext.jsx  общие данные и действия (локально или через API)
  i18n.js         переводы RU / EN / KZ
  utils.js        даты, streak, демо-данные
  pages/          Auth, Habits, Mood, Stats, Exercises, Settings
  components/     Layout, CatFace
public/           manifest, service worker, иконки (PWA)
```

Цвета — в начале `src/index.css`. Новый текст в интерфейсе — добавить ключ во все три языка в `src/i18n.js`.

## Ограничения

- Напоминания — уведомления браузера, пока вкладка открыта. Email-напоминания делает бэкенд.
- Вход через Google пока не подключён.
- Создать привычку без сети нельзя (нужен её id от сервера).
